# Videos

Coloca aquí el video demo de la plataforma.

- Nombre por defecto esperado: **`demo.mp4`** (configurable con `NEXT_PUBLIC_VIDEO_URL`).
- Formatos recomendados: MP4 (H.264 + AAC) para máxima compatibilidad.
